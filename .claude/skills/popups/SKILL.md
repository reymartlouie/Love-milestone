# Popup Optimization

Convert visitors without annoying them.

**Core rule: Easy to dismiss. Never trap or trick.**

## Timing & Triggers

| Trigger | When to Use | Benchmark |
|---------|------------|---------|
| Time-based (30–60s) | General email capture | 2–4% conversion |
| Scroll-based (25–50% depth) | Content engagement signal | 3–5% |
| Exit intent | Last-chance capture | 3–10% |
| Click-triggered | Intent-based, least intrusive | 5–15% |
| Return visitor | Re-engagement | 2–4% |

**Best performing:** Exit intent (highest intent moment) + scroll-based (engagement signal).

**Never:** Show popup immediately on page load. Annoying and earns instant close.

## Popup Types

| Type | Goal | CTA |
|------|------|-----|
| Email capture | Build list | "Send me [thing]" |
| Lead magnet | Qualified leads | "Get the [guide/template]" |
| Discount | Cart recovery / urgency | "Get [X]% off" |
| Announcement | Feature launch, sale | "Learn more" |
| Exit intent | Prevent bounce | Depends on page |

## Copy Formula

```
Headline:   [Specific outcome they want]
Subtext:    [What they get + social proof]
CTA:        [Verb + what they're getting] (not "Submit")
Dismiss:    [Honest option: "No thanks" or "I'll pay full price"]
```

Example:
```
Headline:   Get the SaaS launch checklist
Subtext:    The 47-point checklist used by 3,000+ founders
CTA:        Send me the checklist
Dismiss:    No thanks, I'll figure it out myself
```

## Design Rules

- **Visible close button** — top right, obvious, accessible
- **Mobile:** full-screen overlays work, centered modals feel aggressive
- **Max 1–2 form fields** — email only for most popups
- **Single CTA** — one conversion goal per popup
- **Frequency cap:** show same popup max 1× per visitor per 30 days

## Compliance

- **GDPR:** must have explicit consent checkbox in EU (pre-ticked is illegal)
- **Accessibility:** popup must be keyboard-dismissible (Escape key)
- **Google:** interstitial popups on mobile hurt SEO — use banners instead for mobile

## A/B Test Priority

1. Timing/trigger (highest leverage)
2. Headline copy
3. CTA copy
4. Offer/incentive
5. Design (lowest)

## Measurement

| Metric | Benchmark |
|--------|---------|
| Email popup conversion | 2–5% |
| Exit intent conversion | 3–10% |
| Close rate | Track — high close rate = wrong audience or poor relevance |
