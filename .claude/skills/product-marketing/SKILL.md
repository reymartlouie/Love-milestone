# Product Marketing Context

Creates and maintains `.agents/product-marketing.md` — foundational marketing context referenced by all other marketing skills.

## First Run

Check if `.agents/product-marketing.md` exists:
- **Exists** → summarize what's captured, ask which sections need updating
- **Doesn't exist** → choose path:

**Option A — Auto-draft from codebase** (faster)
Analyze README, landing pages, package.json, and other assets → generate draft → user reviews and refines.

**Option B — Build from scratch**
Walk through each section conversationally, one at a time.

## 12 Sections to Capture

1. **Product fundamentals** — what it is, what it does, the core value
2. **Target audience** — who it's for (company size, industry, role)
3. **Personas** — 2–3 specific buyer/user personas with goals and frustrations
4. **Problems solved** — the pain points, in customer language
5. **Competition** — key competitors and how you differ
6. **Differentiation** — what makes you genuinely different (not just claims)
7. **Objections** — top 3–5 reasons people don't buy + counters
8. **Switching psychology** — what triggers someone to look for a solution like yours
9. **Customer language** — verbatim phrases customers actually use (from reviews, calls, surveys)
10. **Brand voice** — tone, personality, what to avoid
11. **Proof points** — case studies, metrics, testimonials, logos
12. **Business goals** — stage, growth targets, key bets

## Key Rule

**Capture verbatim customer language.** Actual phrases from customers matter more than polished descriptions — they reflect how people really think and search.

## Output

Save to `.agents/product-marketing.md`. Confirm with user before saving.

All other marketing skills (`/copywriting`, `/ads`, `/emails`, etc.) reference this file automatically.
