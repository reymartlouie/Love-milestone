# Prospecting

Build qualified prospect lists across three motions.

## Choose Your Motion

**SaaS** — target software/digital companies using tech stack fit + growth signals (funding, hiring)

**B2B** — target non-SaaS businesses using industry fit + buying triggers (vendor changes, expansion, news)

**Local SMB** — target local businesses using proximity + website status + decision-maker access

## Five-Phase Process

### Phase 1 — Define the ICP

Firmographic criteria:
- Company size (employees, revenue)
- Industry (specific, not broad)
- Geography
- Tech stack (for SaaS)

Buying signal criteria:
- Recent funding
- Specific job postings (signals pain/investment)
- Tech stack changes
- Recent news (new product, new market)

### Phase 2 — Build Candidates

Source 2–3× your target count (attrition from qualification). Sources:
- LinkedIn Sales Navigator
- Apollo.io
- Hunter.io
- Crunchbase (funding signals)
- BuiltWith (tech stack)
- Google Maps (local SMB)

### Phase 3 — Qualify Each

Score against ICP checklist with evidence (source URL for each):
- ✅ Matches firmographic criteria
- ✅ Has buying signal
- ✅ Decision maker identified
- ✅ Contact info verified

### Phase 4 — Score & Prioritize

| Tier | Criteria |
|------|---------|
| 🔥 Hot | Meets all ICP criteria + active buying signal |
| 🟡 Warm | Meets ICP criteria, no immediate signal |
| ❄️ Cold | Partial ICP fit |
| ⛔ Skip | Does not meet minimum criteria |

### Phase 5 — Output Lead Sheet

Markdown table (≤25 rows) or CSV:

| Company | Contact | Title | Signal | Source | Score |
|---------|---------|-------|--------|--------|-------|

## Compliance Rules

- No bulk scraping of LinkedIn, Google Maps, or paywalled platforms
- Email verification required before outreach (Truelist, NeverBounce, or equivalent)
- Capture source URL + date for every contact (GDPR / CAN-SPAM audit trail)
- Public business channels only — no private personal emails

## Handoff to Outreach

After list is built → use `/cold-email` for outreach copy
