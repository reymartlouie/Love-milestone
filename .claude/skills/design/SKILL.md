## Logo Design

### Process
1. Extract brand keywords (3–5 adjectives describing the brand)
2. Select style from 55+ options (see below)
3. Choose color palette (industry-appropriate)
4. Generate SVG-based logo mark + wordmark
5. Deliver: primary, horizontal, stacked, icon-only variants

### Logo Styles (selection)
- Minimalist wordmark — clean type, no icon
- Geometric mark — abstract shape + wordmark
- Lettermark — stylized initials
- Emblem — contained badge/seal style
- Gradient modern — colorful gradient fills
- Vintage/retro — aged textures, classic serif
- Brutalist — raw, unconventional
- Tech/AI — circuit patterns, node graphs

### Color Palette by Industry
| Industry | Primary | Accent | Neutral |
|----------|---------|--------|---------|
| Tech/SaaS | Blue/Purple | Cyan | Cool gray |
| Finance | Navy/Dark blue | Gold | Warm gray |
| Health | Teal/Green | White | Light gray |
| Food/Consumer | Warm orange/Red | Yellow | Cream |
| Creative | Bold any | Contrasting | Black/White |
| Luxury | Black/Deep navy | Gold/Silver | Off-white |

## Icon Design

Generate SVG icons in consistent styles:

| Style | Description |
|-------|-------------|
| Outline | 1.5px stroke, rounded caps |
| Solid | Filled shapes |
| Duotone | Two-tone with opacity |
| Bulk | Bold filled + subtle secondary |
| Linear | Thin 1px geometric |

Rules:
- 24×24px base grid
- 2px minimum stroke
- Export at: 16, 20, 24, 32, 48px
- Never use emoji as icons — SVG only

## Design Principles

1. **Hierarchy first** — size, weight, color guide the eye
2. **Whitespace is intentional** — not empty, breathing room
3. **Max 2 typefaces** per design
4. **60-30-10 color rule** — dominant / secondary / accent
5. **Alignment is everything** — use a grid, snap to it
6. **Contrast for accessibility** — 4.5:1 minimum always
7. **Consistency over creativity** — match established patterns
