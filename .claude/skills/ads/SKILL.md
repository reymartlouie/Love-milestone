# Paid Advertising

Strategy and management for paid campaigns across major platforms.

## Before Starting

Check `.agents/product-marketing.md`. Then gather:
- Campaign goal (leads, signups, revenue, awareness)
- Monthly budget
- Target audience (firmographic or demographic)
- Landing page URL
- Existing campaign data (if any)

## Platform Selection Guide

| Platform | Best For |
|----------|---------|
| Google Search | High-intent buyers actively searching |
| Google Display | Retargeting, awareness at scale |
| Meta (FB/IG) | B2C, visual products, interest targeting |
| LinkedIn | B2B, job title/company targeting, high ACV deals |
| Twitter/X | Developer tools, thought leadership audiences |
| TikTok | Consumer products, younger demographics |

## Campaign Structure

```
Campaign (goal + budget)
  └── Ad Set / Ad Group (audience + targeting)
        └── Ads (creative + copy variants)
```

Never mix audiences in the same ad set — you can't know what's driving performance.

## Google RSA Specifications (mandatory)

- Exactly **15 headlines** (≤30 characters each)
- Exactly **4 descriptions** (≤90 characters each)
- Include primary keyword in at least 3 headlines
- Sitelinks: 4 minimum
- Callout extensions: 4 minimum
- Negative keywords: add before launch

## Targeting Principles

- Start narrow, expand based on data
- Exclude existing customers from acquisition campaigns
- Build retargeting audiences (website visitors, video viewers)
- Lookalike audiences from your best customers

## Creative Framework

**Problem-Agitate-Solve:** State the problem → make it hurt → present your solution

**Before-After-Bridge:** Show current state → desired state → your product as the bridge

**Specific numbers beat vague claims:** "Save 3 hours/week" beats "Save time"

## Weekly Optimization Cadence

- Check spend pacing and budget
- Review CTR — pause ads below 0.5% (search) or 1% (social)
- Check CPA — pause ad sets exceeding target CPA by 50%+
- Review search terms report — add negatives
- Rotate in new creative before fatigue hits (~3–4 weeks)

## Common Mistakes to Avoid

- Launching without conversion tracking
- Fragmenting budget across too many campaigns
- Not excluding existing customers
- Changing bids/budgets too frequently (disrupts learning phase)
- Mixing campaign objectives (awareness ≠ conversion)
