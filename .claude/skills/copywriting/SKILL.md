# Copywriting

Conversion copywriting for web pages. Clear, specific, customer-focused.

## Before Writing

Check `.agents/product-marketing.md` for existing context. If missing, ask for:
- Product and core value
- Target audience and their primary pain
- Page type and primary CTA
- Any existing copy to improve

## Core Principles

- **Simple over complex** — if you have to choose between clear and creative, choose clear
- **Specific over vague** — "reduces reporting time by 75%" beats "saves time"
- **Benefits over features** — lead with what the customer gets, not what you built
- **Customer language** — use the words customers use, not company jargon
- **Active voice** — "Send reports in one click" not "Reports can be sent"
- **Honest claims only** — fabricated claims erode trust and create legal liability

## Page Structure

```
Headline        — what it is + primary benefit (8 words max)
Subheadline     — who it's for + key outcome
CTA             — one primary action, verb-first
Social proof    — logos, numbers, or short quote
Problem section — agitate the pain they know
Solution section— how you solve it specifically
Features        — 3 key features, framed as benefits
More proof      — case study or testimonial with specifics
Final CTA       — repeat the primary action
```

## One Action Per Page

Every page has one primary CTA. Secondary links exist but the page is designed around one conversion goal.

## Page-Specific Guidance

**Homepage** — broadest audience, lead with category + primary benefit, fast to understand in 5 seconds
**Landing page** — single audience, single offer, no nav links, everything supports the CTA
**Pricing page** — anchor with highest tier first, highlight recommended plan, address objections inline
**Feature page** — lead with the job the feature does, not the feature name
**About page** — make it about the customer's journey, not your founding story

## Quality Check

- Does a stranger understand what this is within 5 seconds?
- Is every claim specific and provable?
- Is there one clear CTA?
- Does the copy use customer language or company language?
- Does every sentence earn its place?
