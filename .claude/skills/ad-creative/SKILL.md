# Ad Creative

Generate high-performing ad copy — headlines, descriptions, and primary text — for all major platforms.

## Two Modes

**Mode 1 — Generate from scratch**
Create full ad sets based on product context, audience, and platform.

**Mode 2 — Iterate from performance data**
Analyze what's working in live campaigns, generate variations that build on winning themes while testing new angles.

## Process

1. Gather context (product, platform, audience, performance data if available)
2. Define 3–5 angles (distinct reasons someone would click)
3. Generate multiple variations per angle
4. Validate character limits per platform
5. Organize in upload-ready format

## Platform Character Limits

| Platform | Headline | Description / Body |
|----------|---------|-------------------|
| Google RSA | 30 chars | 90 chars |
| Meta | 40 chars (primary) | 125 chars visible (2,200 max) |
| LinkedIn | 70 chars | 150 chars |
| Twitter/X | — | 280 chars |
| TikTok | 100 chars | — |

## 5 Proven Angles

1. **Problem-first** — lead with the pain: "Tired of [problem]?"
2. **Outcome-first** — lead with the result: "Close deals 2x faster"
3. **Feature-as-benefit** — "Automatic reporting means no more Monday morning scramble"
4. **Social proof** — "500+ teams use [product] to [outcome]"
5. **Contrarian** — challenge the assumption: "Cold email isn't dead"

## Writing Standards

- **Specific numbers beat vague claims:** "Cut reporting time 75%" > "Save time"
- **Benefits-focused:** what the user gets, not what the product does
- **Active voice:** "Send reports automatically" not "Reports are sent automatically"
- **Descriptions complement headlines** — add proof, handle objections, or reinforce CTA
- **Never repeat** the headline in the description

## Output Format

```
ANGLE: [name]

Headline 1: [text] ([char count])
Headline 2: [text] ([char count])
Headline 3: [text] ([char count])

Description 1: [text] ([char count])
Description 2: [text] ([char count])
```
